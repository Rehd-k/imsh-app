# Second pack — later Stitch pages

Not written as full prompts yet. Add a new page in this folder when you want them. Keep **Vivid Care**: overly colorful, lab/hospital/pharmacy photos, slides, bounce, shimmer, pulse.

| Screen | Make it vivid by |
|--------|------------------|
| Radiology list | MRI / X-ray suite photos, modality chips as candy, security banner as a holographic sticker |
| Radiology detail | Image carousel as stories, findings on neon polaroids, payment gate as a sunshine lock card |
| Encounter SOAP | Color-coded SOAP slides: Subjective coral, Objective aqua, Assessment violet, Plan lime |
| Lab trend | Test-tube equalizer chart, analyte picker as a photo filmstrip |
| Vitals trend | Heart / BP as bouncing neon graphs over a ward photo |
| Feedback | Suggestion box photos, complaint as orange ticket, hospital reply as lime speech |
| Family accounts | Polaroid family wall, “viewing child” as a bouncing coral banner |
| Devices | Phone photos with neon status stickers: approved lime, pending orange, revoked magenta |
| Theatre | Operating theatre photos, team as colorful avatar bubbles, status pulse |
| Notifications | Story inbox, each notification a photo card (lab, pharmacy, appointment) |
| Guest emergency + submitted | Same pulse as Prompt 12, then a confetti success with ambulance photo |
| Bill detail + receipt | Colorful itemized tickets, PDF as a bouncing sunshine pill |
| Session expired | Friendly lock dance, sliding return-to-login photo of the colorful lobby |

When writing each page, start with: `Same IMSH Vivid Care design system as the previous screens.` and end with: `OVERLY colorful. More photos. Sliding carousels that peek the next card. Bounce, pulse, shimmer.`
